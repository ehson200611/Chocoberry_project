## Как использовать:

### Вариант 1: Полный деплой (с локального компьютера)

```bash
bash deploy_chocoberry.sh
```

Этот скрипт:
- Копирует весь проект на сервер
- Устанавливает зависимости
- Запускает миграции
- Загружает продукты и подарочные боксы
- Настраивает все сервисы

### Вариант 2: Быстрый деплой (на сервере)

1. Скопируйте файл `deploy_to_server.sh` на сервер
2. Запустите на сервере:

```bash
bash deploy_to_server.sh
```

Этот скрипт:
- Обновляет код
- Устанавливает зависимости
- Запускает миграции
- Загружает продукты и подарочные боксы
- Перезапускает все сервисы

### Вариант 3: Только загрузка боксов (на сервере)

Если нужно только добавить боксы в базу данных:

```bash
cd /var/www/chocoberry
source venv/bin/activate
python manage.py load_gift_boxes
```

## Изменение цен:

Цены можно изменить в файле:
`products/management/commands/load_gift_boxes.py`

После изменения цен запустите команду снова - она обновит существующие продукты.

## Проверка:

После деплоя проверьте:
- Все боксы отображаются в каталоге на сайте
- Цены правильные
- Можно добавить в корзину

```bash
# Проверка статуса сервисов
systemctl status chocoberry
systemctl status chocoberry-frontend
systemctl status nginx
```
